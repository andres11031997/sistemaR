Sistema de Recompensas



Esta actividad es una aplicación de consola en lenguaje C#  que simula un sistema de recompensas para clientes.  

Las compras generan puntos y estos puntos pueden ser redimidos como descuentos en dinero.



Funcionalidades principales

\- Registrar compras y acumular puntos.

\- Consultar puntos acumulados.

\- Mostrar el valor en dinero de los puntos.

\- Redimir puntos y aplicar descuentos.

\- Menú interactivo para múltiples operaciones.

\- Manejo de errores para entradas inválidas.







Tecnologías utilizadas

\- Lenguaje: \*\*C#\*\*

\- Entorno: \*\*Visual Studio Code\*\*

\- Control de versiones: \*\*Git/GitHub\*\*
